## Pourquoi un monorepo ?

Un monorepo pour la formation permet d'avoir une vue d'ensemble sur les différents projets sans avoir à repartager un dépôt systématiquement.

De plus, cela permet d'enregistrer les documents pertinents relatifs à la formation (Ex. le Syllabus)

## Workflow 

Chaque livrable est travaillé dans une branche reprennant le nom final du livrable. Cette branche est push sur le dépôt distant.

Une fois le livrable terminé, celui-ci est mergé dans la branch "main".

Si un livrable spécifie des étapes dans sa réalisation, celle-ci sont précisés dans les commits.
Un commit ne doit pas contenir plus d'une étape. Une étape peut être réalisée en plusieurs commits.s
